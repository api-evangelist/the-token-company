# The Token Company

> LLM input compression middleware. Remove low-signal tokens from prompts to cut costs, improve accuracy, and fit more context.

The Token Company builds compression models (bear-2, bear-1.2) that remove low-signal tokens from LLM prompts before they reach the model. One API call compresses your input; you pass the compressed text to any LLM. Free tier includes up to 1B processed tokens per month. Backed by Y Combinator.

## Installation

- Python: `pip install the-token-company`
- TypeScript: `npm install the-token-company`
